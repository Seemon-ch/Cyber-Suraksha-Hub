# 🛡️ Kavach-AI
> One platform to check phishing links, UPI fraud & data breaches, in Hindi and regional languages.

## Problem

Online fraud is rising fast, and most victims are everyday citizens, including elderly and rural users. Existing tools are scattered: one app for phishing, another for breaches, none for UPI fraud, and almost none in regional languages. People don't need five apps. They need one place to ask: **"Is this safe?"**

## Solution

Kavach-AI is a unified cyber safety hub. Users paste a link, SMS, UPI ID or email into a single **"Check Anything"** box. The app picks the right detector, combines the signals in a **Risk Score Engine**, and returns a clear verdict:

## Tech Stack

- **Frontend:** HTML, CSS, JS, Tailwind CSS, i18n for Hindi/regional languages
- **Backend:** Python, FastAPI
- **ML:** scikit-learn (phishing + anomaly detection)
- **Graph / DSA:** NetworkX, Bloom filter, hashing
- **Database:** PostgreSQL



Kavach-AI is a defensive, educational project built for a hackathon. Verdicts are probabilistic and should not replace official channels. Report fraud at **cybercrime.gov.in** or call **1930**.
